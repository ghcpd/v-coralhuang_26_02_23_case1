Problem description: When SQLMesh renders a SEED (CSV) model, it lowercases/normalizes the CSV header column names. However, in the Postgres dialect, quoted identifiers are case-sensitive. As a result, if the seed model’s `columns(...)` uses a quoted camelCase column name like `"camelCaseColumn"` while the CSV header is `camelCaseColumn`, the DataFrame column names won’t match the model declaration. During `sqlmesh plan`, `render_seed` uses pandas to select/mask columns by name and raises `KeyError: None of ['camelCaseColumn'] are in the [columns]`.
