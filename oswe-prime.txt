  - Normalizing headers by dialect **by default** (unchanged for unquoted columns).
  - If a **normalized** header matches a **declared column**, it renames to the declared name to preserve casing (covers quoted identifiers in Postgres).
- 🔁 `SeedModel` passes declared columns to the reader so `render_seed` no longer raises `KeyError` when `columns(...)` uses quoted camelCase names.

## 📌 Behavior details (Postgres)
- **Quoted columns** in `columns(...)`: casing preserved. Ensure CSV header matches the quoted spelling exactly (e.g., `"camelCaseId"` ↔ CSV header `camelCaseId`).
